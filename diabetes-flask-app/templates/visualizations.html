Dataset Observations

Class Imbalances: Many target variables (e.g., Stroke, HeartDiseaseorAttack, Diabetes_012) exhibit significant class imbalance, which may impact predictive modeling and require careful handling during training.

Evenly Distributed Features: Variables like Sex, Smoker, HighBP, and HighChol show a more balanced distribution, enhancing feature diversity.

Lifestyle Patterns: Variables such as PhysActivity, Fruits, Veggies, and HvyAlcoholConsump indicate respondents generally report healthier behaviors.

Distribution of Diabetes_012

  • Category 0: Majority (~220,000+ samples) do not have diabetes.
  • Category 1: Pre‑diabetes (~100,000 samples).
  • Category 2: Diabetes (~100,000 samples).
  • Observation: Class imbalance indicates need for SMOTE or class weights in modeling.
